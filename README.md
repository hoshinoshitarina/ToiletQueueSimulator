# 厕所排队模拟器：调度危机

一款以公厕排队为主题的轻量调度游戏。角色会分波抵达，忍耐值持续下降；玩家需要判断救援顺序，在周转更快的蹲厕与得分更高的马桶之间取舍，并在关键时刻使用技能，尽量让所有人守住尊严。

项目使用原生 HTML、CSS 与 JavaScript 编写，无需安装框架或构建工具，可直接在本地运行，也适合部署到 GitHub Pages 等静态网站托管服务。

## 游戏内容

- 5 个内置事故场景，并支持创建和删除自定义场景
- 20 名角色，每名角色拥有独立属性、特性、对白与事后评价
- 普通、着急、危急、极限和释放等多种角色头像状态
- 蹲厕与马桶两种隔间：蹲厕周转更快，马桶得分更高
- 安抚与催促两种技能，并带有随机技能掉落
- 轻松、标准、危机三档难度
- 1:1～16:1 倍速、暂停、紧急度排序和大小图标模式
- 角色图鉴、实验参数编辑、自选出场角色和自定义场景
- 浏览器本地存档，以及独立 JSON 存档的导入与导出
- 桌面端与手机端响应式布局

## 如何游玩

1. 选择一个事故现场和难度。
2. 观察等待者的剩余忍耐、角色特性和所需占用时间。
3. 将合适的角色安排进空闲的蹲厕或马桶。
4. 在队伍压力较大时使用“安抚”，在隔间周转过慢时使用“催促”。
5. 所有角色完成救援或失败后，根据得分、成功率和场景挑战获得评级。

更完整的计分公式、角色特性和评级条件可在游戏主页的“玩法与计分说明”中查看。

## 本地运行

最简单的方式是直接用浏览器打开 `index.html`，对于电脑版其几乎必然成功。

如果手机浏览器对本地音频或文件访问有限制，也可以在项目目录启动一个静态服务器，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

有趣的是经过实测，手机版的chrome和firefox反而不可启动，但是大量国产浏览器反而可以本地启动。

## 存档说明

- 游戏设置、自定义场景、角色参数和最高纪录默认保存在当前浏览器的 `localStorage` 中。
- 不同浏览器、设备、域名和本地文件地址之间不会自动共享浏览器存档。
- 可在“游戏设置”中导出 JSON 存档，并在另一台设备或另一个网址中导入。
- 清除浏览器网站数据可能会删除本地存档，重要进度建议定期导出。

## 项目结构

```text
.
├─ index.html          # 页面结构与各游戏界面
├─ styles.css          # 桌面端和手机端样式
├─ game.js             # 游戏数据、规则、状态与交互逻辑
├─ audio/              # 游戏音效
└─ img/
   ├─ thumb/           # 网页默认使用的轻量 WebP 图片
   └─ original/        # 本地或手动启用的高清原图
```

网页版首次打开时会预载轻量图片和音频。高清原图体积较大，默认不会在网页版自动下载；本地运行时会优先使用原图。

## 当前状态

游戏的主要玩法循环、内置内容、存档和响应式布局已经可用。目前更适合继续进行试玩和平衡调整，而不是大量扩充角色或场景。

发布前建议重点确认：

- 不同场景、人数和难度下的计分与评级平衡
- 低性能手机上的动画、刷新频率和文字可读性
- 首次游玩的引导与中段等待节奏
- 图片、音频、字体等素材的来源、授权和署名要求
